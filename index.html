Conhecendo o CSS

O que é CSS?

CSS: significa Cascading Style Sheets, ou, em portugues, Folhas de estilo em cascata.

É a linguagem responsavel por definir a apresentação visual de um documento HTML.

Como trabalhar com o CSS?

Existem tres formas classicas de colocar o CSS em um arquivo HTML:

  • Css inline
  • Css interno
  • Css externo

Conhecendo o CSS Inline

Nessa abordagem, o CSS é colocado diretamente no HTML atraves de um atributo chamado de Style

Aplicando o atributo no elemento.
